Hi, I'm Rosuav, and I'm a geek. Oh, this isn't Geek's Anonymous? Well, I wasn't very anonymous... Anyway. This page exists only as a hub, as a place to host or link to other resources.

The name Rosuav is best known from my use of it on [**Threshold RPG**](https://www.thresholdrpg.com/), an awesome online game if you're at all interested in roleplaying. It's a MUD, so you don't need the latest hardware.
